# Lesson 10: Adding AI to Our Weather Dashboard

## Overview

In this lesson, we will add artificial intelligence (AI) to our existing Streamlit weather dashboard. We will use the Groq API to connect to a large language model (LLM) that generates a written summary of our weather data.

## Learning Objectives

By the end of this lesson, you should be able to:

1. Explain how an application connects to an LLM using an API.
2. Store an API key securely using GitHub Codespaces secrets.
3. Write a Python function that sends data to an LLM.
4. Integrate an AI-generated summary into a Streamlit application.
5. Understand what tokens are and why API token usage matters.

## Lesson Activities

### Step 1: Configure the API Key

- Create or access your Groq account.
- Generate a Groq API key.
- Add `GROQ_API_KEY` to your GitHub Codespaces secrets.
- Verify that Python can access the key.

### Step 2: Create the AI Function

- Create a separate Python file for the AI functionality.
- Import the Groq library.
- Prepare the weather data for the LLM.
- Write a prompt requesting a weather summary.
- Send the request to Groq and retrieve the response.

### Step 3: Integrate AI into Streamlit

- Import the new AI function into the Streamlit application.
- Call the function to generate a weather report.
- Display the AI-generated summary on the dashboard.
- Use Streamlit caching to reduce repeated API calls.

### Step 4: Understand Token Usage

Tokens are small pieces of text processed by a language model. Both the information sent to the model (input tokens) and the response generated by the model (output tokens) contribute to API usage.

We will examine how to retrieve and print token usage for each request.

## Expected Result

At the end of the lesson, your Streamlit weather dashboard should display an AI-generated written summary of the weather data alongside the existing charts and tables.

## Key Concepts

- **LLM:** A large language model that processes and generates text.
- **API:** A way for one application to communicate with another service.
- **API Key:** A credential used to authenticate requests to an API.
- **Prompt:** Instructions and information sent to the language model.
- **Tokens:** Units of text processed by the model.
- **Caching:** Saving a previously computed result to avoid repeating unnecessary API calls.
